# Notebook

Buat notebook ketika eksplorasi atau coding dimulai. Rencana penamaan:

1. `00_eksplorasi.ipynb` - contoh data, karakteristik, dan pemeriksaan kualitas.
2. `01_preprocessing.ipynb` - pembersihan, pembagian data, dan transformasi.
3. `02_algoritma_A.ipynb` - algoritma klasifikasi pertama.
4. `03_algoritma_B.ipynb` - algoritma klasifikasi kedua.
5. `04_evaluasi.ipynb` - baseline, metrik, perbandingan, dan analisis kesalahan.

Ganti A/B dengan nama algoritma setelah dipilih. Notebook tersebut belum dibuat.
