# Data hasil preprocessing

Folder untuk keluaran preprocessing. Catat kode pembuat, versi data asal,
dan langkah yang diterapkan agar hasil dapat dibuat ulang.

Berkas besar yang dapat dihasilkan ulang tidak harus disimpan di GitHub.

Pipeline membuat subfolder lokal `diabetes/`, berisi cleaned.csv, X/y/ID
train-validation-test, matriks sparse, transformer dan metadata. Isi ini
diabaikan Git. Lihat [panduan preprocessing](../../docs/preprocessing.md).
