# Data asli

Dataset disertakan di repo memakai Git biasa:

- `diabetic_data.csv`: 101.766 kunjungan, 50 kolom; 19.159.383 byte.
- `IDS_mapping.csv`: kamus kode administrasi; 2.547 byte.

Sumber asli: [UCI Diabetes 130-US Hospitals](https://archive.ics.uci.edu/dataset/296/diabetes-130-us-hospitals-for-years-1999-2008).
Clore, Cios, DeShazo, dan Strack (2014), DOI `10.24432/C5230J`, lisensi CC BY 4.0.
SHA-256 diabetic_data.csv:
`0689e7ec031237dc63031b938805c48377748761a3b26acab621567afa24df97`.

Simpan dataset asli yang diizinkan untuk dibagikan di folder ini.
Pertahankan isinya sebagai acuan; lakukan pembersihan melalui kode dan simpan
hasilnya di `../processed/`. Sumber dan cara memperoleh data dicatat di
[`../README.md`](../README.md).
