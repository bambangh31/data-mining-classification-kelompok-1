## Catatan pembagian penulisan laporan pertama

Laporan week 13 disusun bertiga pada satu dokumen bersama:

- Bambang: masalah, tujuan/BOD, preprocessing, pembagian dan transformasi data.
- Benedictus: sumber/karakteristik dataset, baseline, evaluasi kedua algoritma,
  hasil, grafik, analisis kesalahan dan keterbatasan.
- Robertus Geraldyn: metode dan model klasifikasi A/B, parameter dan
  konfigurasi percobaan.

Pembahasan, kesimpulan, referensi, penyatuan format dan pemeriksaan akhir
dikerjakan bersama. Setiap anggota menulis dan merapikan bagian sendiri.

Simpan laporan week 13 beserta lampiran dan tautan sumber edit jika digunakan.
Jelaskan tujuan/BOD, dataset, preprocessing, mining, evaluasi, hasil yang
tersedia, keterbatasan, dan tindak lanjut. Format mengikuti arahan dosen.
