# Presentasi

Penyusunan presentasi week 16 dilakukan bertiga pada materi bersama:

- Bambang: masalah, tujuan/BOD dan preprocessing termasuk pembagian/transformasi data.
- Benedictus: sumber/karakteristik dataset, baseline, evaluasi kedua algoritma,
  hasil, grafik, analisis kesalahan dan keterbatasan.

referensi, dan konsistensi format diperiksa bersama. Semua ikut latihan;
aturan pembicara serta durasi mengikuti dosen.
